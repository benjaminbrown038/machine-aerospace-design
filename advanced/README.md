# Design progression

Run the tiers in order, beginning with `python3 run_all.py` at the repository root.

| Tier | What you add to your design process |
|---|---|
| [1](tier-1/README.md) | Size a part for strength and stiffness |
| [2](tier-2/README.md) | Combine different loading modes |
| [3](tier-3/README.md) | Transfer loads through a connection |
| [4](tier-4/README.md) | Evaluate geometry across a range of motion |
| [5](tier-5/README.md) | Compare alternatives against several requirements |

Each README uses the same structure. Each case uses SI input units and generates
a Markdown report plus machine-readable results. Keep the repository intact:
the tier entry points import the shared `designlab` package.
