# Future projects

These are proposed extensions, not implemented capabilities.

| Track | Next project | New analysis | Useful deliverable |
|---|---|---|---|
| Machine | Conveyor drive module | Motor torque/speed, gear or belt ratio, bearing reactions | Shaft/drive assembly and component selection record |
| Machine | Bearing-supported shaft | Bending diagrams, deflection, bearing life | Bearing and shaft sizing workbook or script |
| Machine | Welded stainless frame | Frame loads, weld-group demand, stiffness | Frame drawing, weld map, verification plan |
| Machine | Rotating shaft fatigue | Stress concentration, alternating/mean stress, duty cycle | Fatigue assessment with sourced material data |
| Aerospace | Equipment bracket with holes | Local stress, fastener tension/shear, vibration | Detailed CAD, FEA comparison, mass trade study |
| Aerospace | Pinned clevis and lug | Bearing, net tension, pin bending, load transfer | Joint calculation record and toleranced drawing |
| Aerospace | Door linkage assembly | Kinematics, actuator loads, buckling, joint sizing | Full assembly and motion-envelope review |
| Aerospace | Thin-wall member or panel | Local/global buckling and postbuckling model limits | Buckling analysis and mesh study |
| Aerospace | Thermal mount | Expansion mismatch and temperature-dependent properties | Hot/cold load cases and interface trade study |
| Aerospace | Landing-gear mechanism concept | Motion, load paths, energy absorption assumptions | Concept study with clearly scoped load cases |

The next substantial implementation should be the **bearing-supported conveyor
drive**, followed by the **detailed equipment bracket**. That develops both a
machine assembly and an aerospace component from the same design fundamentals.

Later options include composite laminates, fracture mechanics, fatigue spectra,
modal analysis, and pressure/thermal loads supplied by a CFD project. Each needs
its own model assumptions, references, verification cases, and data provenance.
